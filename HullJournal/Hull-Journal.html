Method, session boundaries & sources

What was measured

1 September–31 October 2026 (UTC), on the exact Exness symbols shown. Each five-minute bar must have a valid two-sided quote in all five minutes. Range = 10,000 × (highest mid − lowest mid) / first mid; mid = (bid + ask) / 2. Each cell is the median of its bar values, not an annualised volatility or a return.

Spread uses the first valid quote in each minute: 10,000 × (ask − bid) / mid. Take the median of those five spreads, then the median across bars. This is a quoted cost benchmark, not fill slippage. No forward-filling or zero bars for closed markets. Fewer than 10 observed UTC dates or 100 complete bars is too thin to rank.

How the clock works

Local weekdays: Sydney 08:00–17:00, Tokyo 09:00–18:00, London and New York each 08:00–17:00. Each bar gets one broad bucket: London + New York first; otherwise London or New York when active; otherwise Asia-Pacific (Tokyo or Sydney); otherwise Off-session. Off-session is retained in the comparison, not ranked.

Opening hours are a separate cut: the first 60 minutes from 09:00 Tokyo, 09:00 Frankfurt or 09:30 New York. City DST is applied per date; these are weekday clock windows, not holiday calendars or CFD dealing hours. Tokyo cash breaks 11:30–12:30 local. Opening-hour bars are not added to session totals.

Read the evidence

The quote benchmark is fixed. Account, size, time frame and filters affect only the journal side. The comparison CSV records the observed entry dates, count, win rate and net results; these need not fall inside the reference period. Session comparison uses the actual opening fill (first fill for a setup), not the signal or exit. Synthetic sample rows are labelled. Use several months of out-of-sample setups before drawing conclusions; this is not a trading rule.

1HZ100V is a 24/7 synthetic, not an exchange index. There is no home cash session or Exness range estimate here. DE40 / DE30 share one DE30m series; never count them twice.

Sources & reproducibility

  • Exness: historical bid/ask quotes · archive servers may differ from your demo feed.
  • Exness index contracts · JPX cash hours · Xetra core hours · NYSE cash hours.
  • RBA: intraday FX volatility · historical cross-check, not the source of these medians. Deriv: synthetic indices.

Desk notes / 01

Using the journal

Actual closes, not chart suggestions

The Windows collector reads MT5 deal history. A partial exit is held until the remaining volume closes. Setups use the signal attached to the actual fills, not the number of legs the scanner planned. The two views are alternative units of analysis, never additive.

Connect or import

With the kit extracted on the MT5 computer, run py -3 journal.py, then open http://127.0.0.1:8765. To enrich the journal with bot receipts and structure types, add --repo "path to bot". For automatic session columns on Windows, install tzdata in that same Python environment if not present. The full Windows steps are in START-HERE.md.

This HTML also works offline. Import tickets.csv, setups.csv or select both together. An import replaces the current dataset; a ticket file alone cannot prove that a setup is complete. No uploaded files leave the browser.

Read the numbers

Net = deal profit + signed commission + swap + fees, including entry costs. Win rate is wins ÷ all closed records, including breakevens. Filters and both charts use the selected unit and close dates. The curve starts at zero for your selection; it is not account equity. CSV times are always UTC; EAT is UTC+3.

Reasons, gross P/L and sessions

The entry reason is the recorded qualifying market-structure setup. Missing evidence is shown as Not recorded, never reconstructed from P/L. The exit reason is from the final broker exit deal; a generic Hull exit does not prove an opposite-signal exit. When the audit contains a unique successful nearby request for the same ticket, its reason is shown separately (for example, opposite Hull label). It is not inferred from an SL or TP. Setups with different ticket exits show Mixed exits.

Gross P/L is signed broker deal profit before commission, swap and fees. Gross gains/losses show positive/negative record contributions separately. Switch Tickets / Setups to change the unit of analysis.

Session buckets use the selected entry or exit timestamp. Analytical FX windows, Monday–Friday in each city: Sydney 08:00–17:00, Tokyo 09:00–18:00, London 08:00–17:00, New York 08:00–17:00. City daylight-saving rules apply. Overlaps get one combined bucket; Off-session is retained. These are not instrument-specific exchange hours or a holiday calendar.
