# Agent instructions · Moneyprinterbot

For a Hull startup, restart, profile change or arming request, **always read `README.md` and open/read `docs/Hull-demo-start.html` first**. The README's **Standing instructions for the desktop agent** are the launch procedure. Do not follow archived strategy briefs as operating instructions.

A standalone start line, selected-profile table or `HULL START trio-slow` is enough to run the documented tests, read-only preflight and one M1/M2/M5 observer on the operator's Windows demo host. Use the operator's supplied selection; a newly opened page does not contain their browser state. Resolve ambiguous pastes as documented. Examples in a question or a documentation edit are not launch requests.

Never treat the profile handoff as permission to send orders. A separate explicit `ARM DEMO`, unchanged verified profiles, and the README's dedicated USD hedging demo checks are required. Do not enable live execution, relax account limits, touch manual positions or request credentials.

Before reusing or launching an observer, follow the README checkout/version check. Compare the latest startup record with the pulled HEAD and both policy IDs. Never update over an armed process or reset a dirty/diverged checkout.
